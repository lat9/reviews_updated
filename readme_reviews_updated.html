What it does

This plugin provides updates to the standard Zen Cart processing of reviews for your products, enabling reviews to be written by guests — controlled by an admin configuration value.

These standard zen-cart database configuration values are used by this plugin:

  • Configuration->Minimum Values->Product Review Text
  • Configuration->Product Info->Product Reviews Require Approval
  • Configuration->E-mail Options->Send Notice of Pending Reviews Emails To - Status
  • Configuration->E-mail Options->Send Notice of Pending Reviews Emails To

These database configuration values are added by this plugin:

  • Configuration :: Minimum Values :: Product Review Write - Guest Reviewer Name (default: 5)
  • Configuration :: Product Info :: Enable product reviews by guests? (default: 0/false)

Installing, Upgrading or Uninstalling

Initial Installation or Upgrade

Start by copying the distribution's zc_plugins directory (and all its files) to the root of your site's file-system. You should see a zc_plugins/GuestReviews sub-directory when completed and …

  1. Login to your Zen Cart's admin
  2. Navigate to Modules :: Plugin Manager.
  3. Click on the row that displays a Plugin Key of GuestReviews and click the associated Install button.
  4. The plugin is now installed!
  5. Review Configuration :: Minimum Values :: Product Review Write - Guest Reviewer Name, changing that minimum length if needed.
  6. Go to Configuration :: Product Info :: Enable product reviews by guests? to enable reviews by guests.

Upgrading From a Non-Encapsulated Version

Versions of this plugin prior to v3.0.0 required a hand-edit of a template's tpl_product_reviews_write_default.php to add the form-fields required for a guest review. If that edit is present, you'll find a code block bounded by a starting

//-bof-reviews_updated-lat9  *** 1 of 1 ***

and ending

//-eof-reviews_updated-lat9  *** 1 of 1 ***

comment. Back out that change (restoring the template file to its original coding); otherwise, you will have two input fields requesting the guest-customer's review name!

Uninstalling

To uninstall Reviews Updated/GuestReviews …

  1. Navigate to your Zen Cart admin's Modules :: Plugin Manager.
  2. Click on the row that displays a Plugin Key of GuestReviews and click the associated Un-Install button.
  3. From the confirmation form, click that Un-Install button. That button-click will remove all the plugin's configuration settings and "inactivate" the plugin.
  4. If you also want to remove the files associated with the plugin, click the Clean Up button.
